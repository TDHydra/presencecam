# PresenceCam Parts List

Everything to order for the motion camera, grouped by what it does. Each line has the term to search for, the specs that matter, and look-alikes to avoid. Tick items as you order them. Ticks are saved in this browser only.

**Before you order:** make sure the main board says **1.47B**, check that the 18650 is a **plain 65 mm cell with solder tabs**, and buy the small parts in packs. They cost little more than singles, and spares save a second order if one gets lost or damaged.

## Already covered, nothing to buy

- **Battery charger:** built into the S3 board. Don't order a TP4056 for this build.
- **Screen and SD card slot:** both are on the S3 board.
- **Arducam library:** bundled with the firmware, so there's no software to buy or install separately.

## When the parts arrive

1. Measure the S3 board, the camera and the VL53L0X with calipers. The case model uses estimated sizes until then.
2. Check the 18650 voltage with the multimeter. A new cell should read 3.5–3.7 V.
3. Check the AO3401's markings and pinout against the seller's datasheet before soldering it to the adapter.
4. Format the microSD card as FAT32.

Quantities are for one device. Product names are examples of the right part, not endorsements, and any equivalent with the same specs works.
